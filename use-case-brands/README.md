# Кейс 3: Диаграмма вариантов использования (Use Case) для раздела «Бренды»

**Задача:** 
Спроектировать функциональные возможности страницы категории «Одежда» на маркетплейсе. Определить, какие действия доступны пользователю, и как они связаны между собой.

**Что было сделано:**
1. Выделил актера (Пользователь) и определил границы системы.
2. Описал основные варианты использования (Use Cases): просмотр списка, поиск, выбор бренда, сортировка и переход к товарам.
3. Смоделировал связи между вариантами использования:
   * `<<include>>` — обязательные действия (например, чтобы перейти к товарам, нужно выбрать бренд).
   * `<<extend>>` — опциональное действие (сортировка списка брендов).
4. Учел бизнес-логику: при выборе бренда отображаются товары и баннеры, а также предусмотрел возможность управления брендами для контент-менеджеров (в тексте ТЗ).
