# Кейс 3: Диаграмма вариантов использования (Use Case) для раздела «Бренды»

**Задача:** 
Спроектировать функциональные возможности страницы категории «Одежда» на маркетплейсе. Определить, какие действия доступны пользователю, и как они связаны между собой.

**Что было сделано:**
1. Выделила актера (Пользователь) и определила границы системы.
2. Описала основные варианты использования (Use Cases): просмотр списка, поиск, выбор бренда, сортировка и переход к товарам.
3. Смоделировала связи между вариантами использования:
include — обязательные действия (например, чтобы перейти к товарам, нужно выбрать бренд),
extend — опциональное действие (сортировка списка брендов).
4. Учла бизнес-логику: при выборе бренда отображаются товары и баннеры, а также предусмотрела возможность управления брендами для контент-менеджеров (в тексте ТЗ).
