## Мои проекты (Кейсы)

### Кейс 1: Проектирование каталога брендов для маркетплейса
**Задача:** Создать страницу категории «Одежда» с возможностью просмотра, поиска и сортировки брендов, а также перехода к товарам выбранного бренда.

**Что было сделано:**
1. Проанализировала бизнес-требования и выделила основные сценарии взаимодействия пользователя с системой.
2. Спроектировала UML Sequence Diagram (Диаграмму последовательности) для сценариев: просмотр списка, сортировка, поиск и переход в товары.
3. Определила границы ответственности сервисов: внутренний `brand-service` (с доступом к БД) и внешний `item-service` (как «черный ящик»).
4. Проработала альтернативные потоки (обработка ошибок) с помощью `alt`-фрагментов: что показывать пользователю, если бренды не найдены или у бренда нет товаров.
